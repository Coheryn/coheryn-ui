# CoherynUI — Next.js App Router Starter Template

Official **CoherynUI** starter for Next.js 14/15 App Router featuring server-safe W3C cascade layers, zero FOUC, and accessible mobile touch ergonomics.

[**Documentation & Homepage**](https://coheryntech.com/coherynui) • [**GitHub Repository**](https://github.com/Coheryn/coheryn-ui)

---

## What's Included

- ⚡ **Next.js App Router**: Clean App Router structure (`app/layout.tsx`, `app/page.tsx`).
- 🎨 **Server-Safe Cascade Layers**: Zero flash of unstyled content with native `@layer cyn.*`.
- 📱 **WCAG 2.2 Touch Ergonomics**: Minimum 44×44px hit bounds (`--cyn-touch-min`).
- 🤖 **Agent-Native Workspace**: Embedded `AGENTS.md` guiding coding assistants.

---

## Quick Start

### 1. Install Dependencies
```bash
pnpm install
# or
npm install
```

### 2. Run Development Server
```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
