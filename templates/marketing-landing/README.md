# CoherynUI Marketing Landing Starter

Modern, dynamic SaaS marketing landing page featuring Liquid Glass and vibrant gradient typography.

## Features
- **Floating Liquid Glass Dock**: Responsive navigation with backdrop blur and specular border highlight.
- **Mesh Gradient Hero**: Multi-stop gradient heading with responsive fluid typography.
- **Adaptive Feature Grid**: Automatically collapses on smaller viewports.
- **Theme Support**: Seamless Dark/Light transition.

## Commands
```bash
# Build stylesheet
coherynui build --input . --output coherynui.css

# Check diagnostics
coherynui check --format json
```
