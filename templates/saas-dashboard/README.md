# CoherynUI SaaS Dashboard Starter

Production-ready cloud analytics and telemetry starter template built with CoherynUI.

## Features
- **Adaptive Sidebar**: Responsive layout grid that collapses elegantly on mobile.
- **Design Tokens**: Configured with canonical `cyn` layer and variable prefix.
- **Live Theme Switching**: Full dark/light mode support using `[data-theme="..."]`.
- **Zero JS Dependencies**: Pure CSS rendering without mandatory browser runtimes.

## Commands
```bash
# Build stylesheet
coherynui build --input . --output coherynui.css

# Check diagnostics
coherynui check --format json
```
