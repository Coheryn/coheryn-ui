W3C Cascade Layer Ordering Architecture

CoherynUI eliminates specificity wars and !important hacks by enforcing strict W3C @layer precedence.

Layer Details: cyn.utilities

Specification Contract

The cyn.utilities layer holds generated atomic classes. Because it has the highest precedence, applying class="btn-primary p-8" will override any padding defined inside .btn-primary without needing !important. 

@layer cyn.utilities {
  .bg-brand { background-color: var(--cyn-color-brand); }
  .p-6 { padding: 1.5rem; }
  .touch-target { min-width: 44px; min-height: 44px; }
  .touch-none { touch-action: none; }
}

Architecture Note

UI Components vs. Native Web Components

UI Components (This Tab): Standard semantic HTML5 + W3C @layer cyn.recipes CSS + optional React bindings (@coheryn/coherynui-react). Operates with 0 kB mandatory JavaScript runtime. Styled via pure cascade classes like .cyn-navbar, .modal-box, and .btn.
Web Components (Next Tab): W3C Custom Elements (<cyn-modal>, <cyn-navbar>) powered by @coheryn/coherynui-web-components. Includes autonomous DOM encapsulation, two-way attribute reflection, lifecycle hooks, and universal support across Vue, Svelte, Angular, Solid, PHP, Django, and Vanilla HTML without React.

Optional Progressive Enhancement
~2.5 kB Brotli data-cyn-* Zero Config

Declarative JavaScript Assist (`@coheryn/coherynui-js-assist`)

CoherynUI is CSS-first. For full WCAG 2.2 Level AA accessibility (focus trapping, roving arrow navigation, outside-click and escape dismissal, focus restoration) without writing imperative JavaScript, include the optional assist script.

INTERACTIVE BEHAVIORAL DEMOS Single Delegated Listener
1. Dialog Modal (`data-cyn-toggle="modal"`) Focus trapped + Trigger restored
2. Popover Dropdown (`data-cyn-toggle="dropdown"`) Outside click & Escape dismiss
3. Accordion / Collapse (`data-cyn-toggle="collapse"`) Automatic aria-expanded sync
The assist layer attaches a single delegated event listener at document root. When elements are injected dynamically via HTMX, Fetch, or SPA page transitions, data-cyn-* attributes work immediately without requiring re-initialization.
4. Accessible Tabs (`data-cyn-tabs`) Arrow key roving focus
Zero-dependency progressive enhancement layer. Works across any server-side rendered HTML, static site, or modern frontend without bundler lock-in.
Built upon @coheryn/ui-core headless primitives with 1 delegated listener for pointer and keyboard interactions.
Under 2.8 kB brotli-compressed. Distributed via npm (@coheryn/coherynui-js-assist) and standalone CDN (coherynui-assist.min.js).

CoherynUI Progressive Enhancement Ladder
Tier 0 (0 kB JS): Pure semantic HTML & CSS recipes (details, dialog, focus-within).
Tier 1 (~2.5 kB): Optional declarative assist (`data-cyn-*`) for auto-ARIA and focus traps.
Tier 2 (Headless): Framework-neutral programmatic core (`@coheryn/ui-core`).
Tier 3 (Web Components): Autonomous custom elements (`<cyn-modal>`, `<cyn-tabs>`).
