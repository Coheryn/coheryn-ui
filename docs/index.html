W3C Cascade Layer Ordering Architecture

CoherynUI eliminates specificity wars and !important hacks by enforcing strict W3C @layer precedence.

Layer Precedence Hierarchy (Lowest to Highest)

Rules in higher layers always take precedence over rules in lower layers, regardless of CSS selector specificity. Click any layer to inspect:

Layer Details: cyn.utilities

Specification Contract

The cyn.utilities layer holds generated atomic classes. Because it has the highest precedence, applying class="btn-primary p-8" will override any padding defined inside .btn-primary without needing !important. 

@layer cyn.utilities {
  .bg-brand { background-color: var(--cyn-color-brand); }
  .p-6 { padding: 1.5rem; }
  .touch-target { min-width: 44px; min-height: 44px; }
  .touch-none { touch-action: none; }
}

Framework Integration Guides

Setup Patterns

Use CoherynUI Custom Elements in any modern JavaScript framework or server-rendered architecture with standard HTML syntax. 

<!-- 1. Include CoherynUI CSS & Web Components -->
<link rel="stylesheet" href="https://cdn.coheryntech.com/coherynui/v1/coherynui.css">
<script type="module" src="https://cdn.coheryntech.com/coherynui/v1/web-components.js"></script>

<!-- 2. Use directly in HTML -->
<cyn-modal id="myModal" title="System Confirmation">
  <p>Zero-runtime overhead modal dialog with automatic focus trap.</p>
  <button class="btn btn-primary" onclick="document.getElementById('myModal').close()">Confirm</button>
</cyn-modal>

<button class="btn btn-primary" onclick="document.getElementById('myModal').show()">Open Modal</button>

<script>
  document.getElementById('myModal').addEventListener('cyn-open', () => {
    console.log('Modal opened!');
  });
</script>
// vite.config.ts - Allow cyn-* custom elements
export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: {
          isCustomElement: (tag) => tag.startsWith('cyn-')
        }
      }
    })
  ]
})

<!-- App.vue -->
<script setup>
import '@coheryn/coherynui-web-components';
import { ref } from 'vue';

const isGpuActive = ref(true);
function onSwitchChange(event) {
  isGpuActive.value = event.detail.checked;
}
</script>

<template>
  <cyn-switch label="Hardware Acceleration" :checked="isGpuActive" @cyn-change="onSwitchChange" />
</template>
// app.module.ts - Enable CUSTOM_ELEMENTS_SCHEMA
import { NgModule, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import '@coheryn/coherynui-web-components';

@NgModule({
  schemas: [CUSTOM_ELEMENTS_SCHEMA]
})
export class AppModule {}

<!-- app.component.html -->
<cyn-modal #modal title="Angular Security Dialog">
  <p>Seamlessly integrated with Angular template reference variables.</p>
  <button class="btn btn-primary" (click)="modal.close()">Save</button>
</cyn-modal>

<button class="btn btn-primary" (click)="modal.show()">Open Modal</button>
<!-- App.svelte -->
<script>
  import '@coheryn/coherynui-web-components';

    isChecked = e.detail.checked;
  }

<cyn-switch label="Dark Theme" checked={isChecked} on:cyn-change={handleChange} />
