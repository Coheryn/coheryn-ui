# @coherynui/cli

> Official Node.js / npx CLI distribution runner for **CoherynUI**.

[![Homepage](https://img.shields.io/badge/docs-coheryntech.com-6366f1)](https://coheryntech.com/products/coheryn-ui)
[![License](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue)](LICENSE)

## Quick Start

You can run the CoherynUI CLI without installing globally:

```bash
npx @coherynui/cli init
```

Or install globally via npm:

```bash
npm install -g @coherynui/cli
coherynui --help
```

Or install the standalone native binary (zero Node.js dependency):

```bash
curl -fsSL https://coheryntech.com/products/coheryn-ui/install.sh | sh
```
